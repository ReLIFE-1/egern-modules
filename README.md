## ⚙️ 使用说明

1. 确保 Egern 已生成并安装 CA 证书，在 iOS **设置 -> 通用 -> 关于本机 -> 证书信任设置** 中开启完全信任。
2. 复制上方 CDN 链接，在 Egern 中点击 **工具 -> 模块 -> + -> 从 URL 安装** 即可添加并启用。
3. 初次使用请彻底杀掉菜鸟 App 后台并重新打开以刷新本地缓存。
